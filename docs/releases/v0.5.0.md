# huck v0.5.0

## A real About dialog

Selecting "About Huck" (or macOS's app-menu equivalent) used to show
jpackage's generic default: the raw package name, a confusing
macOS-only version number, and no real copyright line. It now shows a
custom dialog matching zouk's own: "Huck scan retriever," the real app
version, and a proper copyright.

## A signed macOS `.pkg` installer

macOS is now a real target for Huck, not just local dev testing.
Alongside the existing `.dmg`, releases now include a signed and
notarized `.pkg` installer -- built and signed via zouk's existing
Developer ID certificates and notarization credentials, so Huck didn't
need its own separate signing setup.
