# huck v0.5.3

## Fixed the `.pkg` for real

v0.5.2's install-path fix didn't actually fix the wrong install location
(`/Applications/app/Huck.app` instead of `/Applications/Huck.app`) --
the real cause was a bug in Compose Desktop's own `.pkg`-building task,
confirmed by inspecting the package's payload directly. The `.pkg` is
now hand-built from an already-signed app image, the same way zouk
builds its own installer, avoiding that task entirely.
