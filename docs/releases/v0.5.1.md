# huck v0.5.1

## A working signed macOS `.pkg`

v0.5.0's signed `.pkg` never actually worked: the pipeline built an
unsigned `.app` here and signed it externally in zouk's repo, which
can't reach a native library (Skiko's) bundled inside a `.jar` -- real
notarization failed outright. zouk now checks out this repo's own
source at the release tag and runs the real build itself, using Compose
Desktop's official macOS signing/notarization support, which handles
jar-embedded native libraries correctly.
