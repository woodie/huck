# huck v0.4.1

## Running-dog animation is now a hand-drawn wire-haired pointer

The running-dog animation shown while connecting was still zouk's
original golden retriever recolored gray -- a leftover from the initial
port that an earlier commit's title claimed was already fixed, but
wasn't. It's now a proper hand-drawn wire-haired pointer: a leaner
body, longer legs, a tapered tail, and the breed's bushy eyebrows and
beard. Same 8-frame gallop cycle, same size and timing as before.

## `make package` no longer fails on macOS

`./gradlew packageDistributionForCurrentOS` failed on macOS with "The
first number in an app-version cannot be zero or negative" -- a
jpackage-only rule that rejects a `0.x` major version for the `Dmg`
package, even though the same version works fine for the `Msi` this
repo actually ships. Fixed by giving the macOS package its own version
number, independent of the app's real version.
