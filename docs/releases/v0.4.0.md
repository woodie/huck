# huck v0.4.0

## Placeholder hint text on the host field, matching zouk

The host field on first launch (and the toolbar field once connected)
was blank with no hint about what to type. It now shows "Hostname or
IP address" until you start typing, matching zouk's identical
placeholder on both of its own host fields.

## Brighter in-app icon and README artwork

The dog in the app icon and the README's hero image was much darker
than zouk's golden retriever in a real side-by-side. Lightened the fur
so the two apps' artwork reads as a matched pair.

## Test suite now compares side-by-side with zouk's

`AppModelSpec`/`ScanEntrySpec` are restructured to match zouk's own
spec files' grouping, order, and wording as closely as Kotlin and
Swift allow -- same coverage, same shape, readable as a matched pair
the same way the two apps' Caltrain siblings already are. Along the
way, a few real coverage gaps got closed in both directions: zouk
picked up a `connect()`-fakeable seam it didn't have before, and huck's
delete-failure test now checks `state` the way zouk's always did.
